# Ticket to Ride Europe 
A digital recreation of the classic board game built using Java. This was coded during my CS3 (Data Structures) class, and I implemented many of the structures I learned in the class, such as HashMaps, when coding the project. I worked with a team of 4 others; I was responsible for designing and implementing the data structures to store all the game elements as well as programming the backend gameplay logic. I also designed the trains, cards, station, and button graphics. 

To run the game:
Clone the repository and run the main driver file (Runner.java)
